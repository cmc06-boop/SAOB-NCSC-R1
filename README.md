# NCSC Region I · Flutter Desktop

Offline Windows app para sa **Statement of Allotments, Obligations, and Balances System**. Ito ang hiwalay na Flutter version ng existing Python/PySide6 app. Hindi binago ng project na ito ang Python source.

## Para patakbuhin sa development laptop

1. Install **Flutter stable 3.50.0 or newer** (Dart 3.14+) at **Visual Studio** na may **Desktop development with C++** workload. Magkaibang application ang Visual Studio at VS Code.
2. Buksan itong folder sa VS Code. Ang tamang project root ay yung may `pubspec.yaml`.
3. Sa PowerShell terminal sa project root:

```powershell
flutter --version
flutter doctor -v
flutter pub get
flutter run -d windows
```

Official guides:
- https://docs.flutter.dev/install/with-vs-code
- https://docs.flutter.dev/platform-integration/windows/setup

Kailangan ng internet para sa initial SDK/dependency downloads at unang native build. Offline na ang data, login, Excel processing, PDF generation, at installed app. Walang cloud account, MySQL, XAMPP, o hosting na kailangan.

## Existing data at unang login

Windows data folder ng Flutter app:

```text
%LOCALAPPDATA%\NCSC Region I Finance Flutter\finance.db
```

Kapag unang run at wala pang Flutter database, hahanapin nito yung existing Python database:

```text
%LOCALAPPDATA%\NCSC Region I Finance\finance.db
```

- Isara muna ang Python app bago unang patakbuhin ang Flutter app.
- Kokopyahin nang isang beses ang records, programs, UACS references, fiscal years, accounts, report history, at audit logs. Compatible ang existing Python password hashes.
- Binabasa ang SQLite database mismo, kasama ang committed WAL records; hindi basta kinokopya yung `.db` file nang hiwalay sa WAL.
- Hindi binabago ang original Python data. Sa susunod na run, sariling database na ng Flutter ang gagamitin. Gamitin na ang Flutter version pagkatapos lumipat para doon tuloy-tuloy ang records.
- **Login only:** Walang Sign Up / Create Account o Forgot Password sa released app. Kapag walang account sa bagong installation, makikita ang instruction na kontakin ang system maintainer; naka-disable ang Login button hanggang ma-provision ang account.
- Sa developer laptop na may existing account, **hindi binabago o dini-delete ang account** kapag in-update ang application source.
- Ang database ay nasa Windows profile ng user, hindi sa source folder. Hindi kasama ang actual finance data o passwords sa GitHub.
- **Developer-only initial setup (fresh computer, same Windows user profile as the AO):** isara muna ang app, pagkatapos patakbuhin ang `dart run tools/provision_admin.dart` mula sa source project. Interactive itong hihingi ng pangalan, username, at bagong password (minimum 12 characters; nakatago ang input). Kapag may existing account, tatanggi ang tool at walang babaguhin. Gawin ito bago ibigay ang Release build. Walang account provisioning sa distributed Windows executable.
- Kung kailangan ilipat ang existing data/account, kailangang planuhin ang ligtas na database migration; ang simpleng pag-copy ng `.exe` ay **hindi** kasama ang SQLite data. Huwag kailanman i-commit ang `finance.db` o passwords sa repository.

## Features na kasama

| Menu | Gawain |
| --- | --- |
| Dashboard | Fiscal year, program, at item filters; allotment, obligation, disbursement, balance; program donut chart at utilization rates |
| Budget Utilization | Current/continuing funds; UACS search and lookup; add, edit, delete; automatic balance and rate calculations; pagination |
| Import Records | `.xlsx` selection, worksheet preview, fiscal year/program/fund selection, duplicate detection, invalid-row details, optional updates to matching lines |
| Reports | Budget Utilization, Obligation Status, at Program Budget reports; preview, Excel export, PDF export, native printing; generated report history |
| Audit Trail | Date/time, action, details; year/program/action/date-range filters; pagination; walang user column |
| Programs | Separate sidebar page to add, edit, and delete programs |
| UACS Reference | Separate sidebar page to browse and search expense names and UACS codes |
| My Account (profile button above Logout) | Opens a compact, single-column pop-up with Full Name, Username, and password fields; one Save Changes button; red validation errors only when needed |

Wala nang Settings item sa sidebar. Ang **Programs** at **UACS Reference** ay magkahiwalay na navigation pages, habang ang **My Account** pop-up ay maa-access sa profile button na nasa taas ng Logout. Walang Users, Fiscal Year, System, o Backup & Restore module. Ang My Account ay sariling account lamang, hindi multi-user management. Walang Actions o Generated By column sa Reports. Kapag nagbago ang account password, hindi nito binabago ang budget records o ibang finance data.

Kapag bagong calendar year sa Manila, automatically ginagawa ang bagong fiscal year. Mananatili ang lumang records. Walang automatic na pag-copy ng budget amounts sa bagong taon.

## Windows release build

```powershell
.\tools\build_windows.ps1
```

O manually:

```powershell
flutter build windows --release
```

Output: `build\windows\x64\runner\Release\`.

Ibigay ang **buong Release folder**, kasama ang `data` at DLLs. Hindi sapat ang `.exe` lang. Kapag packaged na, hindi kailangan ni AO ng Flutter, Dart, VS Code, Python, o SQLite installer. Tingnan ang official Windows deployment guide para sa Visual C++ runtime: https://docs.flutter.dev/platform-integration/windows/building

Ang ZIP na ito ay **source project**. Wala pang Windows executable na na-build dito. I-check muna sa Windows ang title bar, file dialogs, printing, at offline release app bago ibigay kay AO.

## GitHub

Puwedeng ilagay muna itong buong project sa `flutter_app` folder sa existing `NCSC-REGION-1` repository para magkahiwalay ang Python at Flutter source. Walang automatic push sa GitHub mula sa ZIP na ito. Ang `pubspec.lock` ay kasama para pareho ang resolved dependency versions; generated build folders at local finance databases ay ignored.
